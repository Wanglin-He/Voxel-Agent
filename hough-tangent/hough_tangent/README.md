# hough_tangent

对视频里的圆盘阵列做霍夫圆检测，然后用**外公切线**把主体外围精确框选出来，最外圈的每个圆盘都被切到。

```
Hough 圆检测  →  圆盘校验  →  4×4 栅格软先验  →  制导重检  →  One Euro 平滑  →  圆凸包切线包络
```

## 跑起来

```bash
uv run --with opencv-python --with numpy python -m hough_tangent 输入.mov -o 输出.mp4
```

自检（不需要视频）：

```bash
uv run --with opencv-python --with numpy python -m hough_tangent.selftest
```

## 六个阶段各自解决什么

**1. Hough 圆检测**（`detect.py`）
`HOUGH_GRADIENT_ALT` 半径准但容易漏掉低对比度的盘，经典 `HOUGH_GRADIENT` 能捞回来但半径糙。两种方法各跑两档灵敏度，结果取并集再按圆心做非极大抑制。这一步**只管召回，不管准确率**——宁可多给，后面有的是办法筛。

**2. 圆盘校验**（`validate.py`）
Hough 在杂乱纹理上会疯狂幻觉：这段素材里板子下方的线缆束一帧能造出上百个假圆。三个便宜的度量就能分开真假：

- **径向支持度**——沿候选圆周采样，看图像梯度是不是真的垂直穿过圆周，且一圈都成立；
- **内外对比度**——盘面内部是不是比外围环亮；
- **饱和度**——白色塑料盘几乎无饱和度，彩色排线则很高。

实测 128 个候选筛到 16 个，耗时 5–14 ms。之后再按**半径众数**收一刀：所有盘尺寸一样，偏离众数超过 26% 的直接丢。

**3. 4×4 栅格软先验**（`grid.py`）
先验只用来**定归属、剔离群、补漏检**，*不*去移动已经测到的圆心——这个阵列在视频里会实际形变，把观测值硬吸附到刚性模型上是在造假。想要硬吸附用 `--snap`。

初始化时从两两位移向量里聚类出栅格基向量。两个坑：

- 4×4 点阵里**对角线邻接对有 18 组，比行/列的各 12 组还多**，方向投票会把对角线选成基向量，于是框歪一整列。靠把长度窗口收到 `[0.60, 1.30]×d₀` 排除掉（对角线在 1.41×d₀）。
- 方向角规范化到 `[0, π)` 之后，近水平的向量会分裂到 0 和 π 两端，跨环合并时取中位数会互相抵消成退化向量。取中位数前先把成员对齐到同一朝向。

假设的打分 = 落进 4×4 窗口的格位数 − 0.75 × 窗口外剩下的候选数。因为校验之后活下来的基本都是真盘，**一个正确的窗口应该能解释掉几乎所有候选**；漏掉一列的窗口会被这项狠狠扣分。

**4. 空格位学习**
4×4 的栅格不等于 16 个盘——这块板子 (1,1) 和 (2,2) 两格是空的。开跑前先抽 60 帧统计每个格位的占用率，从没被观测到的格位标记为空，不再往里面画幻影圆。也可以用 `--cells 1111,1011,1101,1111` 直接指定。

**5. 制导重检**（`detect.refine_in_roi`）
圆盘在阵列形变时会倾斜，俯视投影变成椭圆，全局 Hough 抓不住。对每个漏检格位，只在**预测位置周围的小 ROI** 里重跑一次 Hough，投票阈值可以放得很低——搜索范围被限死了，不怕整帧的假圆涌进来。这一步把召回从 13.1/14 拉到 14.0/14。

**6. 圆凸包**（`hull.py`）
一组圆盘的凸包边界，是**外公切线段和圆弧交替**构成的。用支撑函数求：对外法向 `n(t) = (cos t, sin t)`，圆 `i` 的支撑线在 `h_i(t) = c_i·n(t) + r_i`；凸包的支撑函数就是上包络 `max_i h_i(t)`，在 `t` 处取到最大的那个圆拥有边界点 `c_i + r_i·n(t)`。

于是：**上包络的每一个断点，恰好就是同时切到两个圆的外公切线**。采样 `t` 定出圆的角序，每个断点再解闭式

```
(c_i − c_j)·n(t) = r_j − r_i   ⟹   t = ψ ± arccos((r_j − r_i)/|c_i − c_j|)
```

所以切线是**精确解，不是多边形逼近**。半径不等也照样成立，被别的圆吞掉的圆会自动退出包络。自检里随机 200 组圆盘验证：切线到两个相切圆的距离误差 < 1e-12，且没有任何圆越过切线。

**默认沿最外圈逐个外切，而不是取凸包**（`--outline ring`）。凸包有个固有性质：一条边只与**两端**的圆相切，中间那些略微内凹的圆虽然被包住却永远碰不到。实测这段素材的某一帧，凸包只切到 12 个外圈圆里的 7 个，最大缝隙 20.6px。

栅格恰好告诉了我们哪些格位构成外圈、顺序如何，所以可以放弃凸包，改成**按外圈次序逐对求外公切线**。代价是轮廓不再是凸的：某个圆盘内凹时那里的转向会反过来。

反向转弯处有个无法回避的取舍：**既要是简单多边形、又要严格相切，两者不可兼得**。该处两条切线的交点距圆心 `r / cos(α/2)`（α 是转角），所以轮廓会离盘面差 `r·(sec(α/2) − 1)`。这是个可以写死的界，自检验到 1e-11。实拍全片抽样 92 帧实测：**外圈最大缝隙 0.93px，从未切进任何圆盘，也从未有圆心落到轮廓外**。想要严格相切就得在那里带个小尖刺，得不偿失。

`--outline hull` 切回凸包。

**拐角默认是尖的**：把停在同一个圆上的前后两条切线延长到交点，得到一个每条边都严格相切的多边形。交点距圆心 `r / cos(α/2)`（α 是该圆在包络上占的角跨度），所以 α 趋近半圈时交点会跑到无穷远——超过 `--max-corner`（默认 6 倍半径，对应 α≈161°）的拐角自动退回圆弧。`--corners round` 可以全部走圆弧。

## 常用参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `--grid RxC` | `4x4` | 栅格尺寸 |
| `--cells 1111,1011,...` | 自动 | 直接指定哪些格位有盘，跳过预扫描 |
| `--prescan N` | `60` | 预扫描帧数，用来学空格位 |
| `--corners sharp\|round` | `sharp` | 拐角走切线交点（尖角）还是沿圆弧 |
| `--max-corner N` | `6` | 离圆心超过 N 倍半径的尖角退回圆弧 |
| `--margin-frac F` | `0` | 包络外扩，单位是盘半径的倍数 |
| `--tangent-extend PX` | `0` | 把切线延长出切点若干像素，视觉上强调"这是切线" |
| `--snap 0..1` | `0` | 0 = 用实测圆心，1 = 吸附到栅格模型 |
| `--work-width` / `--out-width` | `1080` | 检测分辨率 / 输出分辨率 |
| `--stride N` | `1` | 每 N 帧取一帧，调参时用 |
| `--debug` | 关 | 灰色画出校验前的全部 Hough 候选 |
| `--no-grid` | 关 | 关掉栅格先验，直接框原始 Hough 结果（诊断用） |

## 这段素材上的实测结果

- 全程 1830 帧锁定率 100%，只初始化了 1 次，从未丢失；
- 每帧 14/14 个圆盘全部**真实检出**，没有一个是模型脑补的；
- 每帧平均只有 0.17 个未归属的杂圆（最多 3 个）；
- 1080p 输出约 6.4 fps，30 秒 4K 素材约 5 分钟跑完。

## 换个拍摄对象

不是 4×4 就改 `--grid`。完全没有栅格结构的话用 `--no-grid`——此时只剩 Hough + 圆盘校验 + 圆凸包，抖动会明显一些，因为没有先验来补漏检。

被测物体不是白色的话，改 `validate.DiscProfile`：`bright_on_dark`（亮底还是暗底）、`max_saturation`（颜色有多鲜艳）、`min_contrast`（内外亮度差）。
